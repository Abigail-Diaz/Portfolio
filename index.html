DuckDB PX4 ULog Extensionin progress

500MB binary parsed in 180ms — ~2.7 GB/s

A native C++ DuckDB extension that reads raw PX4 binary drone flight logs (.ulg) directly into vectorized memory blocks using zero-copy memory mapping. Removes the Python/CSV conversion step that usually sits between a flight log and a query.

UDP Telemetry Ingest & Ring-Buffer Dispatcherin progress

A multi-threaded C++ daemon that receives live binary telemetry over UDP, as from a drone or rocket at a ground station. Packets land in a lock-free ring buffer and a worker thread pool parses and dispatches them in real time, so the socket never blocks.
